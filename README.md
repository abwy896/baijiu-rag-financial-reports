# 作业3｜白酒行业上市公司财报 RAG（全新重建版）

本包是一个全新的项目目录，适用于你已删除之前本地文件的情况。保留方向A，目标为10家白酒上市公司2025年年度报告。**不包含API Key，不伪造测试成绩。**

## 最简单的操作方式（Windows）

1. 下载 ZIP 后右键选择“全部解压缩”，不要在压缩包预览里运行。
2. 打开解压出来的文件夹，双击 **`一键初始化并启动.bat`**。
3. 首次运行会安装Python依赖、从原公开GitHub仓库下载真实知识块，并从官方年报PDF重新解析贵州茅台和口子窖，修正茅台页码错位并补入口子窖。请保持黑色窗口打开，等待程序完成。
4. 启动脚本会提示输入DeepSeek API Key。粘贴后按回车时，屏幕不会显示字符，这是正常的。可选择是否保存到本机 `.env`；`.env` 已在 `.gitignore` 中排除，绝不要上传密钥。
5. 浏览器自动打开后，页面公司覆盖应显示 **10/10**。若未自动打开，可访问 http://localhost:8501。
6. 后续只需双击 **`只启动问答页面.bat`**；如果关掉黑色窗口，网页会停止，重新双击即可。

## 这次具体修复什么

- 原始知识块由公开仓库下载，保留其他公司的原有真实数据。
- 贵州茅台：从官方2025年年度报告PDF重新切块，以PDF物理页码作为引用页码；不会把报告印刷页码误当成PDF物理页码。
- 口子窖：从2025年年度报告PDF解析并加入知识库，不再只显示0条。
- 修复前会备份 `data/chunks/all_chunks.jsonl`，新块采用明确的 `company/report/pdf_page/section/text/source_url/chunk_id` 字段。
- 来源链接分为“PDF直达”和“官方公告/年报入口页”；入口页不会冒称PDF直达。
- API Key在启动器中输入，输入时不回显；可选择保存到本机 `.env`。

- 双击 `批量测试10题.bat` 运行真实检索与模型回答；测试结果写入 `data/results/`。

- `docs/一页结论草稿_需真实测试.pdf` 是草稿，不是最终实测成绩。请基于真实运行记录更新后再提交。

- GitHub提交前检查 `.env` 和密钥；不要把原始PDF上传到仓库。

## 如果启动失败

- **`requirements.txt` not found**：说明没有在完整解压的项目根目录启动。应在同一层看到 `requirements.txt`、`code`、`data` 和 `.bat` 文件。
- **无法下载GitHub知识块或PDF**：检查网络；不要删除旧数据。错误会显示在黑色窗口末尾。
- **公司覆盖仍非10/10**：把初始化完成时的公司块数列表截图发回；不要手动填数字。
- **仍显示 `no_api_key`**：先关闭当前运行窗口，再双击 `只启动问答页面.bat`，按提示重新输入Key；确认输入后启动器才会把Key传给Streamlit进程。
- **模型下载很慢**：首次BGE模型下载可能较慢。可在网页侧栏临时切换TF-IDF兼容模式用于排障，但最终报告应如实注明使用的检索模式。

## 官方报告来源目录

`data/source_catalog.csv` 提供每家公司的PDF直达链接或官方公告入口。非PDF直达的入口页需再点开对应的2025年年度报告，页面会明确标记这一点。
